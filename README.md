# وثيق — بوابة فحص الأرقام

## الميزات

- دخول وتسجيل حسابات، وصلاحيات في الباك إند.
- الفحص بالكتابة أو قراءة QR والباركود بالكاميرا، ثم مراجعة الرقم قبل الفحص.
- اسم ووصف وحالة فعال/موقوف لكل رقم.
- قائمة أرقام للأدمن مع بحث وترقيم صفحات وتعديل وتفعيل وإيقاف وحذف.
- استيراد CSV حتى 1000 صف، مع كشف التكرار والتحقق قبل كتابة أي صف.
- سجل عمليات الأدمن بالوقت والحساب والقيم قبل وبعد العملية.
- سجل آخر 10 فحوصات وإحصائيات خاصة بكل مستخدم.
- تغيير كلمة المرور، واستعادتها عبر البريد، وتفعيل حسابات التسجيل الجديدة.
- بيانات الحساب وربط بريد بالحسابات القديمة التي لا تملك بريداً.
- تصميم عربي من اليمين إلى اليسار يتكيف مع الموبايل والكمبيوتر.

## تحديث الموقع الحالي

1. فك الضغط.
2. افتح نفس مستودع GitHub، ثم Add file ثم Upload files.
3. ارفع محتويات id-check-api فوق الملفات القديمة، مع مجلد static كاملاً. لا ترفع مجلد id-check-api كطبقة إضافية ولا ترفع local.db.
4. اضغط Commit changes.
5. انتظر نشر النسخة في Render. إذا لم يبدأ تلقائياً استخدم Manual Deploy ثم Deploy latest commit.
6. افتح الموقع وسجّل الدخول. أضف رقماً باسمه ووصفه، ثم افحصه من حساب المستخدم.

لا تنشئ خدمة أو قاعدة بيانات جديدة. startCommand الحالي يشغّل init_db تلقائياً. التحديث ينشئ جداول إضافية ويحافظ على الأرقام والحسابات القديمة. السجلات القديمة تبدأ فعالة بلا اسم أو وصف. الحسابات القديمة تظل قابلة للدخول، أما الحسابات التي تسجل بعد هذا التحديث فتحتاج تفعيل البريد.

## إعداد إرسال البريد على Render

تم تجهيز التكامل مع Resend عبر HTTPS. لا تستخدم SMTP على خطة Render المجانية لأنها تمنع منافذ البريد المعتادة.

في Environment لخدمة الويب أضف

| المتغير | القيمة |
| --- | --- |
| RESEND_API_KEY | مفتاح إرسال من حسابك في Resend |
| MAIL_FROM | عنوان إرسال ضمن نطاق موثّق في Resend، مثل Wathiq <noreply@your-domain.com> |
| PUBLIC_BASE_URL | رابط موقعك الفعلي عبر HTTPS دون شرطة في النهاية، مثل https://id-check-api-borw.onrender.com |

احفظ وأعد النشر. لا تضع المفاتيح في GitHub أو داخل HTML. خدمة البريد تحتاج حساباً وإعداد نطاق إرسال من مالك المشروع. عنوان Resend التجريبي لا يرسل بالضرورة لكل المستخدمين، لذلك استخدم عنواناً موثّقاً قبل فتح التسجيل للناس.

بدون هذه الإعدادات، يسجل المستخدم الجديد لكن يبقى بانتظار التفعيل، وتوضح الواجهة أن البريد يحتاج إعداداً. حسابا التجربة القديمان يعملان. بعد إعداد البريد، يطلب المستخدم إعادة إرسال التفعيل من صفحة الدخول.

إذا لم تصل الرسالة، راجع سجل الإرسال لدى مزود البريد ومجلد الرسائل غير المرغوبة. استجابة طلب الاستعادة لا تكشف إذا كان البريد موجوداً. إن فشل مزود البريد، لا تعرض رسالة الطلب العامة دليلاً على تسليم الرسالة.

الحسابات القديمة التي لا تملك بريداً يمكنها ربط الاسم والبريد من «بيانات الحساب»، مع كلمة المرور الحالية. يتطلب ذلك إعداد البريد أولاً. بعد الربط، يسجّل خروج الحساب ويحتاج تفعيل البريد. البريد الموجود يعرض للقراءة فقط في هذه النسخة.

## الكاميرا والكتابة

الكتابة هي الخيار الافتراضي. الكاميرا تفتح بطلب المستخدم فقط. تعمل على HTTPS أو localhost مع إذن الكاميرا. يوجد قارئ ZXing مضمّن في static للمتصفحات التي لا تدعم BarcodeDetector، ويقرأ QR والباركود. لا يعتمد وقت التشغيل على CDN.

محتوى الرمز يجب أن يكون ID نفسه، مثل 00123، وليس رابط موقع أو نصاً طويلاً. بعد المسح يوضع الرقم في الحقل، ويضغط المستخدم فحص. إذا رفض المستخدم الإذن أو تعذر فتح الكاميرا، تظهر رسالة تسمح بمتابعة الكتابة. الكاميرا تتوقف بعد القراءة أو الرجوع للكتابة أو الخروج أو إخفاء الصفحة. لا ترفع صوراً أو فيديو إلى الخادم.

هذه نسخة ويب، وليست تطبيق متجر Android أو iOS. يجب تجربة الكاميرا على الأجهزة الفعلية المستهدفة بعد النشر.

## CSV

```csv
id,name,description,active
00123,رقم تجريبي,وصف الرقم,true
00456,رقم آخر,وصف آخر,false
```

id إلزامي، وباقي الأعمدة اختيارية. لا تغير أسماء الأعمدة. active يقبل true/false أو 1/0. الحقل يقبل 1–64 حرفاً إنجليزياً أو رقماً أو شرطة أو _. الاسم حتى 120 حرفاً والوصف حتى 2000. حجم الملف أقل من 800 كيلوبايت. حد الاستيراد 1000 صف.

الأرقام المكررة داخل الملف أو الموجودة في قاعدة البيانات تُتجاوز ولا يُستبدل وصفها. إذا ظهر خطأ في صف، لا يُستورد أي صف حتى تصحيح الملف. الأصفار الأولى تحفظ كنص، لذلك عند تجهيز الملف في Excel اضبط عمود id كنص قبل الإدخال. تحميل نموذج CSV متاح للأدمن.

الإيقاف يبقي الرقم، وتظهر نتيجة exists=true مع active=false. الحذف يزيله من قائمة الأرقام لكن يسجل أثر الحذف في سجل الأدمن. سجل المستخدم يحتفظ بنتيجة الوجود وقت الفحص. الاسم والوصف يظهران لأي مستخدم مسجّل يفحص الرقم.

## API للموبايل

POST /api/login
```json
{"username":"jehad","password":"123456"}
```
يرجع token. أرسله في Authorization: Bearer TOKEN. المتصفح يستخدم كوكي HttpOnly وSameSite=Strict وSecure على Render.

POST /api/check
```json
{"id":"00123"}
```
مثال النتيجة
```json
{"id":"00123","exists":true,"active":true,"name":"اسم الرقم","description":"الوصف"}
```

| المسار | الوظيفة |
| --- | --- |
| POST /api/register | full_name,email,username,password — الدور دائماً user |
| POST /api/resend-verification | email |
| POST /api/verify-email | token |
| POST /api/forgot-password | email |
| POST /api/reset-password | token,password |
| POST /api/change-password | current_password,password |
| GET /api/profile | بيانات حسابك |
| POST /api/profile | ربط بريد لأول مرة مع full_name,email,current_password |
| GET /api/me | الحساب والدور |
| GET /api/dashboard | سجل وإحصائيات حسابك |
| POST /api/logout | إلغاء الجلسة |
| GET /api/records?q=...&page=1 | بحث قائمة الأرقام، للأدمن |
| POST /api/records | id,name,description,active للإضافة، للأدمن |
| PATCH /api/records | الحقول السابقة وversion للتعديل، للأدمن |
| DELETE /api/records | id للحذف، للأدمن |
| POST /api/import-csv | csv كنص، للأدمن |
| GET /api/audit?page=1 | سجل الأدمن |

401 دخول مطلوب. 403 صلاحية غير متاحة أو حساب غير مفعّل. 409 سجل مكرر أو تعارض تعديل. 429 طلبات كثيرة. 400 بيانات غير صالحة. 503 تعذر الوصول للخدمة أو إعداد البريد غير مكتمل. لا تعامل 503 كأن الرقم غير موجود.

## التشغيل والتحقق المحلي

```bash
python3 app.py
python3 -m unittest -v
```

افتح http://localhost:8000. SQLite محلياً وPostgreSQL عند وجود DATABASE_URL. ملفات static مطلوبة لقراءة الكاميرا. لا ترفع قاعدة SQLite المحلية إلى المستودع.

اختبارات الباك إند تستخدم SQLite وتختبر الترحيل والصلاحيات وتغيير كلمة المرور والتفعيل والاستعادة والروابط أحادية الاستخدام وحدود الطلبات وتعارض التعديل والـCSV وسجل الأدمن. البريد محاكى أثناء الاختبار ولا تُرسل رسائل حقيقية. PostgreSQL وإرسال البريد والكاميرا على الهاتف يلزم اختبارها بعد نشر النسخة وإعداد الخدمة.
