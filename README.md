# وثيق — لوحة الأدمن وAPI فحص مفتوح

## طريقة العمل

الأدمن يسجل الدخول إلى الموقع، ويرفع ID مع النص والصورة والفيديو. تطبيق الموبايل يرسل ID فقط دون مستخدم أو كلمة مرور أو token. إذا كان الرقم فعالاً، يرجع النص وروابط الصورة والفيديو. إذا كان غير موجود أو موقوف يرجع غير متاح فقط.

لا يوجد تسجيل مستخدمين للتطبيق، والتسجيل العام في الموقع معطّل. الموقع مخصص للأدمن. حساب jehad القديم لم يعد صالحاً للدخول إلى لوحة الإدارة، والحسابات القديمة لا تعطى صلاحية أدمن.

حساب الأدمن الموجود abo_liath وكلمة المرور الابتدائية 123456، إلا إذا غيّرتها سابقاً. إعادة النشر لا تعيد كلمة المرور القديمة.

## تحديث الموقع

1. فك الضغط وارفع محتويات id-check-api فوق النسخة السابقة في نفس مستودع GitHub.
2. ارفع مجلد static كاملاً، مع app.py وindex.html وباقي الملفات.
3. اضغط Commit changes وانتظر نشر Render.
4. لا تنشئ قاعدة بيانات أو خدمة جديدة.
5. افتح الموقع وسجّل دخول الأدمن. أضف رقماً واربطه بالمحتوى.

التحديث يحافظ على الأرقام القديمة ويضيف جداول للمحتوى والملفات. الوصف القديم يستخدم كنص في API للأرقام التي لم يُضف لها نص مستقل.

## رفع المحتوى

من «إضافة رقم» أو «تعديل» تستطيع إدخال ID والاسم والوصف والنص، ورفع صورة وفيديو.

- النص حتى 10000 حرف.
- الصورة JPEG/PNG/WebP حتى 5 ميجابايت.
- الفيديو MP4/WebM حتى 25 ميجابايت.
- لا يجري تحويل ترميز الفيديو. اختر فيديو متوافقاً مع الهاتف المستهدف.
- رفع ملف جديد يستبدل ارتباط الملف السابق. توجد خيارات إزالة الصورة والفيديو.
- الاسم والوصف للتنظيم في لوحة الأدمن، والنص هو المحتوى المرسل للتطبيق.
- وجود الصورة والفيديو اختياري؛ API يرجع null لأي ملف لم يُرفع.
- حفظ ملف مرفوع لا يجعله متاحاً للعامة حتى تربطه برقم فعال وتحفظ الرقم.

الملفات تحفظ كبيانات داخل PostgreSQL، لذلك لا تضيع بسبب ملفات القرص المؤقت على Render. هذه طريقة تناسب النسخة الصغيرة، وكل ملف يستهلك من مساحة قاعدة البيانات. يتم تحميل محتوى الفيديو من القاعدة لمعالجة الطلب، مع دعم طلبات الأجزاء. للتوسع إلى فيديوهات كثيرة أو كبيرة، انقل التخزين إلى خدمة ملفات مستقلة. الملفات القديمة المستبدلة والمرفوعة دون ربط تبقى في القاعدة في هذه النسخة ولا توجد شاشة تنظيف لها.

## API للمبرمج

راجع API_Mobile.md. الطلب العام

POST https://id-check-api-borw.onrender.com/api/check
Content-Type: application/json

```json
{"id":"00123"}
```

مثال متاح
```json
{"available":true,"message":"متاح","id":"00123","text":"نص الرقم","image_url":"https://YOUR-SERVICE/media/IMAGE_ID","video_url":"https://YOUR-SERVICE/media/VIDEO_ID"}
```

غير موجود أو موقوف
```json
{"available":false,"message":"غير متاح"}
```

يرجع روابط مباشرة للملفات، وليس الملفات داخل JSON. الروابط متاحة دون تسجيل دخول إذا ربطت برقم فعال. محتوى أي رقم فعال متاح لمن يعرف الرقم؛ لا تضع محتوى خاصاً في هذه الحقول.

لضبط الروابط على نطاقك، استخدم PUBLIC_BASE_URL عبر HTTPS. إذا لم تضبطه، يستخدم RENDER_EXTERNAL_URL عند توفره، ثم عنوان الخدمة في الطلب.

## ميزات الإدارة

بحث وتعديل وتفعيل وإيقاف وحذف، استيراد CSV حتى 1000 صف، وسجل العمليات مع الحساب والوقت والبيانات قبل وبعد. رفع CSV يضيف الأرقام وأسماءها وأوصافها، ثم تُربط الصور والفيديوهات من شاشة التعديل. الأرقام المكررة تتجاوز دون استبدال المحتوى.

الإيقاف يحافظ على البيانات لكن يمنع إرسال المحتوى في API. الحذف يزيل الرقم والارتباط بالملفات، مع بقاء أثر العملية في سجل الأدمن. روابط الملفات التي لا ترتبط بأي رقم فعال لا تعمل.

فحص الكاميرا أو الكتابة موجود في لوحة الأدمن للتجربة، ويمكن للمبرمج تطبيق الخيارين في تطبيق الموبايل. الكاميرا لا تعمل تلقائياً، والقراءة تتم على الجهاز، ثم يظهر الرقم للمراجعة.

## بريد الأدمن

المستخدم العام في التطبيق لا يحتاج بريداً أو رسالة تفعيل. استعادة كلمة مرور الأدمن عبر البريد تبقى متاحة بعد إعداد Resend وربط بريد الأدمن من «بيانات الحساب».

متغيرات Render

| المتغير | القيمة |
| --- | --- |
| RESEND_API_KEY | مفتاح خدمة Resend |
| MAIL_FROM | عنوان إرسال من نطاق موثّق |
| PUBLIC_BASE_URL | رابط موقعك الفعلي عبر HTTPS |

لا تضع المفاتيح في GitHub. ربط بريد الأدمن يحتاج خدمة البريد جاهزة وكلمة المرور الحالية، ثم تفعيل البريد. تغيير كلمة المرور من اللوحة لا يحتاج خدمة بريد ويُلغي الجلسات القديمة.

## تشغيل محلي

```bash
python3 app.py
python3 -m unittest -v
```

SQLite محلياً وPostgreSQL عند وجود DATABASE_URL. لا ترفع local.db. اختبارات SQLite تغطي الفحص العام دون بيانات دخول، وصلاحيات الأدمن، ورفع الملفات والتحقق من النوع، وربط النص والصورة والفيديو، وإخفاء المحتوى الموقوف، وطلبات أجزاء الفيديو، وتعارض التعديل والـCSV والترحيل.

اختبار واجهة محاكى يغطي رفع الملفات وربطها والفحص العام ومعاينة المحتوى والخروج. اختبار PostgreSQL وكاميرا الهاتف وتشغيل فيديو حقيقي على الأجهزة المستهدفة يتم بعد النشر. ملفات ZXing وتراخيصها ضمن static.
